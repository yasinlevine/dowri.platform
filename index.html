    تنظیمات انتشار

    برای اینکه قیمت‌ها و عکس‌ها برای همه‌ی مشتری‌ها دیده شود، تغییرات روی GitHub ذخیره می‌شود. فقط یک بار یک «توکن» بسازید: GitHub ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token. فقط مخزن همین سایت را انتخاب کنید و در Permissions گزینه‌ی Contents را روی Read and write بگذارید.
